# TUSF Website V7 — Root-Ready GitHub Version

This version is specifically prepared for the way your GitHub repository is currently organized.

All images and the logo are in the repository root, alongside:

- `index.html`
- `styles.css`
- `script.js`
- `CNAME`

There is no `assets` folder in this version.

## Replace your current GitHub files

1. Open your GitHub repository.
2. Delete the current website files.
3. Upload every file from this package directly into the repository root.
4. Commit the upload.
5. Wait 1–3 minutes.
6. Refresh `www.tusfumbanda.org`.

## Important

Do not upload the ZIP file itself.

Unzip it first, then upload all individual files together.

The custom domain file is already configured for:

www.tusfumbanda.org
